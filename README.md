# Kahoot-Helper
Fast, stealthy Linux Kahoot bot using Google Gemini AI, multi-key API load balancing, and minimalist tray bar notifications.

# ⚡ Kahoot Winner (Linux Automation)

An automated, low-footprint Linux tool designed to solve Kahoot questions in real-time using computer vision and Google Gemini's multimodal API. 

Engineered for maximum speed, stealth, and resilience.

### ✨ Key Features
* 🚀 **AI Vision Engine**: Lightning-fast image analysis using Google Gemini Flash models.
* 🛡️ **Multi-Key Load Balancing**: Automatic Round-Robin key rotation across an API pool to prevent rate-limit errors (429).
* 🥷 **Stealth Indicator**: Non-intrusive 2.5-second color-coded response flashing directly in the system tray bar.
* ⌨️ **Global Hotkeys**: Background execution using `F9` to trigger screen capture and `F10` to terminate safely.
* 📦 **Automated Setup**: One-command installation script (`setup.sh`) for all System (APT) and Python dependencies.
